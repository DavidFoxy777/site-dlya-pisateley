# Визуальный Автор

Сайт-курс для писателей, которые хотят делать визуальный контент с ИИ:
обложки, буктрейлеры, оформление Telegram-канала и автопостинг.

Собран на Flask + Jinja. Дизайн — в стиле Zerocoder: тёмная база,
лаймовый акцент, моношрифтовые подписи, карточки услуг, длинные
маркированные списки.

## Как запустить

```bash
./run.sh
```

Сайт откроется на <http://127.0.0.1:5000>.

Другой порт или адрес:

```bash
./run.sh --port 8080
./run.sh --host 0.0.0.0
./run.sh --reload          # автоперезапуск при правках
```

Если запуск вручную:

```bash
python3 -m pip install -r requirements.txt
python3 app.py
```

## Как править контент

Весь текст живёт в `content.json`. Правьте его и обновляйте страницу —
перезапускать сервер не нужно, файл перечитывается автоматически.

Проверить, что JSON не сломан:

```bash
python3 -m json.tool content.json
```

Если в файле опечатка, вместо сайта появится страница с объяснением
и точной командой для проверки.

### Ссылки на обучение

Сейчас все ссылки пустые — это нормально для первой версии. Кнопки
нарисованы и кликабельны: при клике показывается подсказка, что
адрес надо вписать в `content.json`.

Чтобы кнопки заработали по-настоящему, заполните:

```json
"cta": {
  "lead":        "https://t.me/your_channel",
  "leadProgram": "https://...",
  "leadTariff":  "https://...",
  "leadCase":    "https://...",
  "leadBottom":  "https://...",
  "support":     "https://t.me/your_support",
  "payment":     "https://...",
  "consult":     "https://...",
  "materials":   "https://...",
  "zoom":        "https://...",
  "bot":         "https://...",
  "telegramChat":"https://t.me/..."
}
```

Ключ означает, где стоит кнопка:

| ключ | где |
|---|---|
| `lead` | главная, верхний экран |
| `leadProgram` | страница программы |
| `leadTariff` | страница тарифов |
| `leadCase` | страница кейсов |
| `leadBottom` | нижний блок заявки на всех страницах |
| `support` | кнопка «Поддержка» в шапке |
| `payment` | оплата тарифа |
| `consult` | бесплатная консультация |
| `materials` | материалы курса |
| `zoom` | созвон |
| `bot` | бот с уроками |
| `telegramChat` | чат в Telegram |

### Контакты

Там же, в секции `contacts`:

```json
"contacts": {
  "email":  "hello@example.ru",
  "phone":  "+7 900 000-00-00",
  "telegram": "https://t.me/your_channel"
}
```

Поддерживаются `email`, `phone`, `telegram`, `whatsapp`, `vk`,
`telegramChannel`, `youtube`, `dzen`.

Почта и телефон автоматически превращаются в `mailto:` и `tel:`.
Пустое поле не ломает вёрстку — вместо ссылки будет заглушка.

### Домен

```json
"site": { "domain": "https://vazualnyj-avtor.ru" }
```

Нужен для `sitemap.xml` и `robots.txt`. На localhost можно оставить пустым.

### Аналитика

```json
"analytics": { "yandexMetrikaId": "123456", "ga4Id": "G-XXXXXXXXXX" }
```

Пока поля пустые, счётчики не подключаются и на скорость сайта не влияют.

## Форма заявки

Форма на `/contacts` отправляет JSON на `/api/lead`. Проверить вручную:

```bash
curl -X POST http://127.0.0.1:5000/api/lead \
  -H 'Content-Type: application/json' \
  -d '{"name":"Анна","contact":"@anna","email":"a@a.ru","tariff":"start","task":"Обложка","consent":"1"}'
```

Что происходит с заявкой:

1. Проверяются имя, контакт и согласие на обработку.
2. Если задан `form.endpoint` — запрос уходит туда (например, в CRM или
   в Telegram-бот через прослойку).
3. Если не задан — заявка пишется в `data/leads.json` и печатается
   в терминал.

Файл `data/leads.json` в `.gitignore`: реальные заявки не попадут
в репозиторий.

## Что проверено

- все страницы отдают 200, неизвестный адрес — 404;
- битый `content.json` даёт понятную страницу ошибки, а не пустой экран;
- форма принимает заявку и отвечает на ошибки;
- в разметке нет экранированных тегов вида `&lt;b&gt;`;
- на телефоне таблица тарифов прокручивается, меню не перекрывает контент.

Осталось проверить в браузере: анимации фона, плавную прокрутку,
поведение мобильного меню и отправку формы с реального устройства.
JavaScript не запускался в headless-браузере — синтаксис проверен
чтением кода, а не исполнением.
